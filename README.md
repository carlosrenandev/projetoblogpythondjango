# Blog com Django

Um blog desenvolvido com Django, com sistema de autenticação de usuários e criação de posts pela comunidade.

## Funcionalidades

- Cadastro de usuários
- Login e logout
- Opção "Lembrar de mim"
- Criação de posts
- Visualização de posts
- Busca de posts por título
- Exclusão de posts
- Controle de permissões
- Mensagens de feedback para o usuário

## Tecnologias utilizadas

- Python
- Django
- SQLite
- HTML
- CSS
- Tailwind

## Estrutura do projeto

- Autenticação de usuários utilizando o sistema nativo do Django
- CRUD básico de posts
- Proteção de rotas com `login_required`
- Sistema de mensagens com `django.contrib.messages`
